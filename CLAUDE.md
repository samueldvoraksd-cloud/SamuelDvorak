# personal-site

Samuel Dvorak's personal brand site (Node.js/Express/EJS). See the repo's own `README.md` for stack and structure.

## Deployment

This repo is connected to Render (`samueldvorak.onrender.com`) with auto-deploy on push to `main` — any `git push` here goes live immediately.

**Always ask Samuel for explicit confirmation before pushing to `main`.** Make and commit changes locally as normal, but stop and confirm before the push step specifically, even if earlier pushes in the same session were already approved. Wait for a clear go-ahead each time before publishing.
